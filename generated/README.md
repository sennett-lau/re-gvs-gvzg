# Generated game code

`gundam-vs-z-gundam/` is the retained C++ translation of the supported SLPS-25419 executable, 325 MWo3 modules and recorded VU programs. These are game-derived translations, not the original developer's handwritten source.

The directory contains 1,186 files totaling 296,865,530 bytes (283.11 MiB). The largest individual file, `table.cpp`, is 64,222,424 bytes (61.25 MiB). Each file fits ordinary Git's 100-MiB limit. [manifest.json](manifest.json) records every size and SHA-256.

Keep this input unchanged. The hook preparation tool verifies and patches five generated units into a separate build directory. The runtime build links those replacements before the base generated archive. Neither the ISO nor a personal memory card is included here.

The game build uses this complete translated source tree; it does not need a historical object archive. Regenerating EE code from a supported disc and replaying VU recording are distinct operations from compiling the retained C++.
