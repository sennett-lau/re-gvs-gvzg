# Project instructions for coding agents

Read [CONTRIBUTING.md](CONTRIBUTING.md) before changing code or documentation. Its content placement, duplication checks and validation workflow apply to agents and human contributors.

Read the existing Wiki and relevant evidence before adding an explanation. Update the canonical section when a topic already exists.

Keep contributor procedures and version plans in the secondary Contributing area. Keep the overview focused on project purpose and the reading path.

Follow the user's account, publication and silent-testing rules. A local task does not authorize a remote push or pull request.
